# LOOP

LOOP is a full-stack customer feedback intelligence app.

## Features
- Authentication and account management
- Workspace and team collaboration
- Feedback capture, search, filters, CSV import, and deletion
- Dashboard metrics with sentiment charts
- Executive report generation and PDF export

## Run locally

### Backend
```bash
cd backend
npm install
npm start
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

The frontend expects the backend at http://localhost:8080/api.
